# Сценарий демонстрации backend-а

1. Показать `docker compose up --build`.
2. Открыть `/health` и `/swagger`.
3. Зарегистрировать первого пользователя и объяснить bootstrap ADMIN.
4. Показать login и получение JWT.
5. Создать пост через upload endpoint.
6. Выполнить поиск постов по тегам.
7. Показать comments / notes / favorites.
8. Показать moderation queue, bans и audit logs.

## Почему это подходит под тему

Это полноценный клиент-серверный backend для базы изображений с ролями,
moderation-потоком и поиском по тегам в стиле Danbooru.
